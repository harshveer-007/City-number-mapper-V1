# City-number-mapper
A simple Python project that maps cities to unique numbers and allows dynamic registration of new cities.

A simple Python project built while learning dictionaries and basic program logic.

## 📌 What it does

- Takes a number as input and returns the corresponding city
- Allows users to add a new city if the number is not found
- Automatically assigns a new number to each new city
- Prevents duplicate city entries

## 🧠 What I learned

- How dictionaries store and map data
- Checking for keys and values efficiently
- Using built-in functions like `max()` for dynamic behavior
- Writing cleaner logic without unnecessary loops
